# worklog/ — резервная копия всего необходимого для работы

Эта папка — страховка. Все рабочие инструменты, данные и журнал лежат не только
на рабочей машине, но и здесь, в GitHub. Если рабочая машина недоступна,
из этого репозитория можно восстановить всё: и сайт, и инструменты, и историю работ.

## Что внутри

| Путь | Что это |
|------|---------|
| `WORKLOG.md` | Полный журнал работ: что делалось, когда, какими коммитами |
| `autosync.log` | Отчёты робота-автосинка: каждая реальная доза новых постов (пишет сам робот) |
| `scripts/build_fund_json.py` | **Главный скрипт**: пересобирает `src/data/fund.json` из снимков данных |
| `scripts/vk_sync.py` | Первичный сбор ленты ВК (тексты + детали + фото) |
| `scripts/vk_fetch_missed.py` | Добор постов по прямым ссылкам `/wall-223846998_XXXX` |
| `scripts/download_missed_imgs.py`, `download_images.py` | Скачивание фото в HD (трюк: `cs=` поднимается до максимума из `as=`) |
| `scripts/fetch_brand_eva.py`, `download_brand_eva.py`, `prepare_brand_imgs.py` | Фирменные материалы (обложка, логотип) и фото детей |
| `scripts/shot_*.py` | Локальные скриншот-проверки сайта (Playwright + http.server) |
| `scripts/poll_workflow.py`, `ab.py`, `debug_pw_vk.py` | Помощники: ожидание прогона Actions, работа с браузером |
| `data/` | Снимки данных ВК, из которых собирается fund.json (рабочий набор + исторические) |

Робот автосинка (`scripts/ci_vk_sync.py` в корне репо) и его расписание
(`.github/workflows/vk-sync.yml`) уже лежат в самом репозитории — они в бэкапе не нуждаются.

## Как пересобрать сайт с нуля (из чистого клона)

```bash
git clone https://github.com/gdp888/bf && cd bf
python3 worklog/scripts/build_fund_json.py   # пересоберёт src/data/fund.json из worklog/data
npm ci && npm run build                      # соберёт сайт в dist/
```

Скрипт сам находит свои данные (рядом или в `worklog/data`) и сам находит репозиторий.
Пути можно переопределить переменными окружения: `FUND_REPO` (где репо) и `FUND_DATA` (где снимки).

## Гарантии от потери данных

1. **Посты не теряются при пересборке**: всё, что добавил робот-автосинг и чего нет
   в статических снимках, переносится из текущего `fund.json` как есть (carry-over),
   а если при сборке какой-то пост исчез — сборка падает с громкой ошибкой.
2. **Фото** живут в `public/images/` внутри репозитория (VK-ссылки протухают, поэтому
   всё скачивается локально).
3. **Кадрирование фото детей** задаётся полем `image_pos` у каждой истории
   (`'top'` — показать верх снимка, `'center 30%'` — точку фокуса), чтобы головы не срезались.

## Правило работы

После каждой значимой задачи в `WORKLOG.md` дописывается секция (и коммитится сюда же),
новые скрипты/снимки складываются в эту папку. Так бэкап не устаревает.
